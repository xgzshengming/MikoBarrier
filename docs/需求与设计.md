## 断网档位的语义

| 档位 | 自律期间 | 中场休息 |
| --- | --- | --- |
| 不断网 | 不处理 | 不处理 |
| 温和档 | hosts 屏蔽网站名单 | **继续屏蔽** |
| 狠人档 | hosts + 禁用网卡 | **继续断网** |

应用屏蔽则相反：**自律时生效，中场休息自动放开**。

## 密码与找回体系

1. 主密码：PBKDF2-SHA512 / 210,000 次迭代 / 16 字节盐，只存哈希
2. 恢复码：16 位（4 组  4 位），只显示一次，只存哈希
3. 安全问题：3 个，问题自定义；答案归一化（转小写 + 去空格）后哈希，必须 3 题全对

## 崩溃恢复设计

- 每约 10 秒把完整快照写入 `data/session.lock`（计划、阶段、轮次、阶段剩余秒数、已完成秒数、开始时间）
- 启动时若发现快照  询问"继续上次的自律 / 放弃本次"
- 只有"主动输入密码提前结束"才写中断记录并产生欠债

## 技术选型

- C# + .NET 8 + WPF（+ WinForms 的 NotifyIcon 做托盘），自包含单文件发布
- 无边框窗口用 `WindowChrome`；圆角用 DWM 属性；最大化边界用 WM_GETMINMAXINFO 钩子
- 数据：JSON（`data/config.json`、`data/stats.json`），无数据库依赖
- 计时：`Stopwatch` 单调时钟，改系统时间无法作弊
- 自检：核心逻辑 SmokeTest（v0.5.0 为 180 项；巫女模式追加第 16 节后 185 项）+ `--ui-smoke-test` 界面自检（v0.5.0 为 80 项；巫女模式追加探针后 89 项，必须隔离 `MikoBarrier_HOME`）

## 强制约束的层次（v0.3 起逐步实现）

1. **窗口层**：全屏置顶遮罩、拦截关闭消息（v0.2 已有关不掉窗口）
2. **键盘层**：`WH_KEYBOARD_LL` 低级键盘钩子，吞掉 Alt+Tab / Alt+F4 / Win / Ctrl+Esc
   - 拦不住：`Ctrl+Alt+Del`、`Win+L`（不完全可靠）、长按电源键、拔电、安全模式
3. **进程层**：按名单裁决（黑名单杀 / 白名单放行），系统关键进程永远放行
4. **网络层**：hosts / 禁用网卡，退出或崩溃后自动恢复
5. **守护层**：Guard 看门狗互守  升级为 Windows 服务（SYSTEM，失败自动重启）
6. **恢复层**：崩溃快照 + 自动还原网络 + 密码 / 恢复码 / 安全问题三重保险

## 巫女模式（v0.6.0-Miko）

- **解锁入口**：仅在全屏计时里显示左下角「裂缝」；在本次全屏计时内累计点击 3 次后弹出确认框「你引起了巫女小姐的注意！是否进入真·巫女结界？」，按钮为「是 / 否」。
- **确认后**：`MikoModeUnlocked = true`、`MikoModeEnabled = true`；自动套用「真·巫女」主题；裂缝永久隐藏；后续可在「系统设置 → 外观与启动」的「界面模式」里随时切回普通模式。
- **文本范围**：主界面、全屏计时、设置、名单 / 任务 / 统计页、主要弹窗；帮助 / 引导由 `MikoHelpContent` 提供逐条重写的巫女版全文（20 个 topic）。交互文案静态 XAML 走 `MikoText` 映射表，动态消息走 `T()` 润色；任务名、路径、程序名等用户数据不参与翻译。
- **主题**：进入巫女模式会自动套用第 11 套主题「真·巫女」：背景纯白，高饱和、略带橙粉调的朱红作为强调色；未解锁时主题对话框不显示该预设，配置解析也会回退到默认主题。
- **边界**：巫女模式只改变文案与解锁主题，不改变任何安全语义；关机 / 注销放行、全屏禁用 Topmost、Win 键放行、逃生按钮、会话结束顺序全部保持原样。
- **自检**：核心 SmokeTest 第 16 节（解锁策略与持久化 5 项）；`--ui-smoke-test` 覆盖主题可见性、文案切换 / 还原、裂缝三连击、自动套用主题、20 个帮助 topic 逐条重写、真实主窗口文案。


## 已知限制（需要在 UI 中如实告知）

- `Ctrl+Alt+Del`、强关机、安全模式无法拦截
- 无签名内核驱动方案不安全，不采用
- 键盘钩子 + 进程拦截 + 自启服务可能被杀软误报，需要加排除项
