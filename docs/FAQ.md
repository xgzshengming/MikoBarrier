# MikoBarrier 常见问题（FAQ）

> 只针对本机、你自己使用。它不是家长控制 / 员工监控软件，也不要把密码交给别人。

## 使用前

### 会不会把我锁死？

不会。安全语义是设计的第一条：

- **关机 / 注销永远无条件放行**，程序会先写标记、保存状态、还原网络封锁，然后绝不阻拦 Windows；
- 全屏计时里始终有「提前收工（暗号）」通道：输入密码或用恢复码即可结束；
- 恢复码的本机副本（DPAPI 加密）可以在设置页或密码弹窗里查看，不需要联网。

### 需要管理员权限吗？

- 只做「结束进程」的普通自律：不需要；
- **温和档 / 狠人档断网**、**全局键盘封锁**：需要。程序里点「系统设置 → 以管理员身份重启」即可一键提权。

### 支持哪些系统？

Windows 10 / 11（x64）。界面是 WPF + Win32 自绘，暂不支持 Linux / macOS，也没有手机端。

### 断网会不会把我永久断网？

不会。断网分两档：

- **温和档**：把网站名单写进 `hosts`；
- **狠人档**：`hosts` + 禁用网卡。

程序退出、崩溃或重启后会还原；异常残留时下次启动也会自动还原，也可以手工检查 `C:\Windows\System32\drivers\etc\hosts` 中的 MikoBarrier 标记。

### 黑名单模式和白名单模式怎么选？

- **黑名单**：平时更省心，适合"只戒几个游戏 / 视频网站"；名单内的进程会被结束。
- **白名单**：更狠，只放行名单内（及系统保护层）的有窗口程序，适合备考、赶工期。第一次用建议先在名单页跑一次「白名单体检」，确认不会误伤你的工作软件。

### 白名单会不会误杀系统进程？

白名单模式会永远放行系统核心进程（explorer、dwm、svchost、输入法、音频引擎、Defender 等）、内置必需组件（杀软、显卡 / 音频面板、触控板等）和 Windows 系统目录里的程序，并且只拦截"有窗口"的程序，服务 / 驱动 / COM 宿主 / 计划任务不会被杀。详见 README 的「白名单保护模型」。

## 退出与安全

### 忘记密码怎么办？

两条路：

1. 设置过的 3 个安全问题全部答对，可重设密码；
2. 用恢复码结束本次自律，或用恢复码重设密码。

### 密码 / 恢复码有什么限制？

- 用密码提前退出：每天第 1 次成功后冷却 1 小时，第 2 次 2 小时，第 3 次后冻结到次日 00:00；
- 用恢复码提前退出：每天 1 次；
- 用恢复码重设密码不限次数，但不会解除当天的密码冷却 / 冻结。

### 强行结束 MikoBarrier 进程可以绕过去吗？

可以试试，但代价是欠债：App 和 Guard 每秒写心跳互保，任何一方被杀，另一方会在几秒内记 Kill 事件并自动把对方拉起来，且带 `--killed-restart` 继续本次自律。本自然月第 n 次 Kill 罚 5n 分钟（5、10、15…），当月余额封顶 60 分钟，跨月清零。

### 提前退出会怎样？

未完成的自律时长会记入下一场的第一轮（提前退出欠债），单次封顶 120 分钟，按自然月清空；主动中断不计入完成次数。

### 拔电源 / 蓝屏了怎么办？

异常中断会留快照，下次启动询问"继续还是放弃"；如果有互保 Kill 记录，则会自动续跑，不提供放弃入口。

## 杀软报毒 / SmartScreen 拦截怎么办

MikoBarrier 会枚举进程、结束进程、改 hosts、禁用网卡、写开机自启和计划任务——这些行为和部分恶意软件重合，所以可能被启发式引擎或 SmartScreen 误报。

- 请只从 **GitHub Releases** 下载，并核对 `SHA256SUMS.txt`；
- 发布版目前**没有代码签名**，SmartScreen 的"未知发布者"提示点「更多信息 → 仍要运行」即可；
- 源码、构建脚本、自检全部公开，可以自己 `tools\publish.ps1` 编译一份；
- 如果杀软（火绒 / 360 / 腾讯等）误报，请把安装目录加入信任区，或到 Issues 反馈误报信息；
- 误报不影响程序本身的行为：没有任何联网上传，也不会改动你的数据目录之外的文件（断网档位会改 hosts / 网卡，退出时还原）。

## 功能

### 和其他番茄钟比怎么样？

| | |
| --- | --- |
| 普通番茄钟 | 计时 + 统计，靠自觉退出 |
| 屏蔽类工具（如 Cold Turkey） | 强约束，但多为闭源 / 付费，防杀和中文支持不一定齐 |
| MikoBarrier | 开源免费、中文、多轮任务统计 + 进程拦截 + 断网 + 键盘封锁 + 双进程互保 + 欠债机制 |

详情见 [对比同类工具](对比同类工具.md)。

### 支持多显示器 / 高 DPI / 竖屏吗？

支持。全屏结界按屏幕工作区自适应，对话框也会按屏幕尺寸收敛。

### 为什么有"巫女模式"？

全屏计时左下角点击 3 次裂缝即可解锁的彩蛋：把帮助、引导、提示全部换成巫女口吻，并解锁白底朱红的「真·巫女」主题。它不改变任何安全语义。

### 战绩分享卡是什么？

「自律统计」页可以一键导出一张 900×1200 的 PNG 战绩卡（今日时长 / 完成次数 / 拦截统计 / 累计成绩 / 连续天数），保存在数据目录的 `share\` 下，可以直接发到聊天或社交平台。

## 数据、隐私与卸载

### 数据存在哪？

按顺序取第一个可用位置：

1. 环境变量 `MikoBarrier_HOME`；
2. 已存在的 `D:\MikoBarrier` / `F:\MikoBarrier` / `E:\MikoBarrier`；
3. `%LocalAppData%\MikoBarrier`。

### 会上传数据吗？

不会。无遥测、无联网上传；密码与安全问题只存哈希，恢复码本机副本用 DPAPI（CurrentUser）加密。

### 怎么完全卸载？

见 README 的[卸载与清理](../README.md#卸载与清理)一节（关闭自启 → 退出 → 删除程序目录 → 删除数据目录 → 清理计划任务 / 启动项）。
