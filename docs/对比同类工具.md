## 各自适合谁

- **只想有个计时提醒、不想被强制**：系统自带的专注助手或普通番茄钟就够了。
- **主要想屏蔽网站 / 应用，且只用 Windows / macOS**：Cold Turkey Blocker 更专注，功能也成熟。
- **想用种树游戏化、手机端为主**：Forest / 番茄 ToDo 更合适。
- **想在 Windows 上"说到做到"**：需要一个能拦住自己、又能在紧急情况下安全退出的工具时，MikoBarrier 的组合（进程 + 断网 + 键盘 + 互保看门狗 + 欠债机制）才是差异化所在。

## MikoBarrier 不适合的场景

- 家长控制、员工监控、给别人装：项目定位就是"约束自己"，README 与帮助里都反复强调；
- Linux / macOS / 手机：不支持；
- 只想用通知提醒、不想装强约束软件：杀鸡用牛刀。

## 选型时值得问自己的三个问题

1. 我需要"提醒"还是"拦住"？（提醒用番茄钟，拦住才需要进程 / 网络 / 键盘层面的工具）
2. 万一有急事（视频会议、线上答辩、客户电话），我能不能体面地退出？（MikoBarrier 的答案是：关机 / 注销随时可以，密码或恢复码可以提前收工）
3. 我介意数据上云吗？（MikoBarrier 无遥测、全部本机）
